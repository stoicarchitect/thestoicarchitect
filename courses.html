How every course is built

The same architecture, every pillar

  1. A framework recap

    Each module opens by placing the pillar back inside the whole framework, so nothing is learned in isolation.

  2. Marcus, worked through

    Every exercise is shown first on Marcus, a composite case study, with real numbers and real mistakes.

  3. A workbook that does the work

    Lessons run six to ten minutes. The workbook is where the change happens, built to fit a real week.

  4. A clear cost of stopping

    Every module ends with what finishing gets you, and what not finishing costs. No countdown timers.
